# Xiaomi TV Remote Control (Android TV)

Нативный Wi-Fi + Bluetooth пульт управления для Android TV (Xiaomi TV) на Kotlin и Jetpack Compose (Material 3).

## 📲 Скачать и установить на телефон в 1 клик

👉 **[Скачать APK (app-debug.apk)](https://github.com/Otsgolyak/Remote_control/releases/latest/download/app-debug.apk)**  
👉 **[Скачать APK (Remote_control-v1.0.0.apk)](https://github.com/Otsgolyak/Remote_control/releases/latest/download/Remote_control-v1.0.0.apk)**
